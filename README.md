# autocaptionfinal

AI-powered auto caption and quotation generator website with template fidelity and ASS subtitle rendering.

## Quick Start

```powershell
cd autocaptiongenerator-c20ca5f9452b76564a4383f87609b6e976c08f64
pip install -r requirements.txt
python app.py
```

Open `http://localhost:8000` in your browser.
